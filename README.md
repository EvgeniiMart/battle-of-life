# Функционал
Игрок имеет возможность:
* Перемещать камеру и менять её масштаб
* Менять скорость симуляции и ставить её на паузу
* Манипулировать состоянием клеток вручную
* Размещать заранее заготовленные структуры (глайдер, глайдерная
пушка и космический корабль) под различными углами

# Локальный запуск

localhost, перейдя в папку [WebBuild](WebBuild) и использовав команду

# Технические подробности
В игре присутствует два скрипта: [PatternSpawner](Assets/Scripts/PatternSpawner.cs)
и [SimulationControl](Assets/Scripts/SimulationControl.cs). Из названий очевидно, что
первый отвечает за хранение, поворот и размещение заготовленных паттернов, а второй
— за всю симуляцию (конкретнее: считывание клавиш, изменение скорости симуляции, проверку
нажатия мышкой и координат курсора мышки, совершение шагов симуляции, изменение состояний
клеток).

Конкретно симуляция реализована через два HashSet<Vector2Int>, где один всегда
хранит реальное настоящее положение клеток, а второй копирует значение из первого в начале
шага симуляции (тем самым замораживая его состояние) и на основе данных из второго сета
в шаге обновляется первый.
